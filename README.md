# InputFlow Studio

![InputFlow Studio](Assets/App.png)

当前版本：**2.1.0**

Windows 键鼠自动化工具，支持录制与回放、步骤编辑、组合快捷键、循环倍速、方案管理及深浅色中文界面。

Windows x64 键鼠自动化工具，使用 C#、.NET 10、WPF。由 MouseFlow Studio 更名而来，图标更新为键盘、鼠标和流动箭头。为保持旧版兼容，应用标识不变，升级沿用原安装目录；安装包更新程序文件和快捷方式，不迁移或清空方案。方案及设置仍位于 `%APPDATA%/MouseFlowStudio`，安装升级不会主动删除用户数据。

## 联网更新（2.1.0 起）

主界面和“设置 → 关于与更新”均可检查更新。默认启动时检查，每 24 小时最多自动请求一次；可关闭自动检查。自动检查失败不打断操作，手动检查显示结果。录制、回放、倒计时及其他弹窗期间只暂存新版本信息，空闲后提示。

更新源固定为 `Kairos-Leeway/InputFlow-Studio` 的正式 GitHub Releases，忽略草稿和预发布版本，按数字版本比较，拒绝降级。支持“稍后”“跳过此版本”，手动检查可重新显示跳过的版本。设置页内发现更新后，会在关闭设置、结束当前任务后显示下载选项。

安装流程：查看说明 → 下载 → 校验大小与 GitHub SHA-256 → 核对安装包产品版本与 Release 标签 → 用户确认“安装更新并退出” → 处理未保存方案 → 关闭应用并启动正常安装向导。取消退出时不会启动安装，已下载文件保留，启动安装前再次校验。安装缓存位于原 AppData 数据目录的 updates 子目录；整个过程保留已有方案文件。

安装包缺少可验证的 SHA-256、版本不一致、下载中断或文件损坏时，均不执行安装。客户端不保存 GitHub 令牌，使用公开 API。网络请求仅用于版本信息及用户确认后的安装包下载，不上传方案或录制数据。

**首次启用：** 2.0.1 及更早版本没有更新模块，需手动安装一次 2.1.0；之后才能在应用内检测和下载后续版本。

### 发布后续版本

1. 同时修改 InputFlowStudio.csproj 的 Version 和 setup.iss 的 MyAppVersion，例如 2.1.1。
2. 执行 build.ps1，脚本会校验两个版本一致，生成 installer/InputFlowStudio-2.1.1-Setup.exe 和 SHA256SUMS.txt。
3. 提交源码，在 GitHub 创建正式 Release，标签使用 v2.1.1，上传对应版本安装包，确认设为最新正式版本。不要只提交源码或重复上传旧安装包。
4. GitHub 为安装包附件提供 digest，客户端据此校验。Setup.exe 名称也兼容，推荐版本化文件名。可选附上传 SHA256SUMS.txt 供人工核验。

更新检测使用 [GitHub 官方 Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)；发布了预发布版本或没有安装包附件，不会自动执行任何安装。

## 开发、检查和打包

安装 .NET 10 SDK、Inno Setup 6 或 7。

```powershell
dotnet run --project InputFlowStudio.csproj
dotnet run --project tests/EngineChecks.csproj
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 自定义 Inno Setup 路径：
.\build.ps1 -IsccPath 'E:\Application\Inno Setup 7\ISCC.exe'
```

独立运行版本位于 `publish-v2/`，安装包位于 `installer/Setup.exe`。

## 编辑、保存与还原

编辑的是内存中的工作稿。F10 拾取坐标、输入参数、调整倍速、重命名、增删或排序步骤，都不会直接改写已保存方案。

- 橙色边框：参数、步骤或方案存在未保存修改。
- 参数旁的 **↶**：只还原这个参数到最近成功保存的值。
- **还原当前步骤**：还原该步骤所有参数；新增且未保存的步骤会被移除。
- **撤回修改**：撤回最近的模型修改，包括增删、排序、参数修改和还原操作；F10 的 X/Y 作为一次操作撤回。每个方案最多保留 100 项，成功保存后清空该方案的撤回记录。
- **还原整个方案**：恢复最近保存的名称、次数、间隔、倍速、步骤内容和顺序。删除的步骤也会恢复。整次还原可再撤回。
- **保存**：只保存当前方案，其他方案未保存的工作稿保持不变。保存失败时保留修改标记、基准和撤回记录。

需要确认的弹窗采用独立窗口；主窗口隐藏或最小化时，不将弹窗绑定到不可见主窗口，而是置前显示并提供任务栏入口，无须先手动打开主界面。

点击运行，如果当前方案有修改，会提示“保存并运行 / 取消”；取消时既不保存也不回放。没有修改时直接运行。输入错误或保存失败会阻止运行。退出时如有修改，会提供保存、放弃修改或取消退出的选择。

方案名称不允许为空或重名，忽略首尾空白与英文大小写。新建、复制、导入会自动分配唯一名称；重命名会检查重复。读取旧版同名方案时保留数据并修复名称。尚未保存的旧名称会继续保留，避免还原时与其他方案冲突；撤回重命名时也检查冲突。

删除方案前确认，并立即持久化删除结果。删除步骤只修改工作稿，保存前可撤回或还原整个方案。保存、删除及错误有顶部反馈。

## 键盘操作与热键录入

2.0 新增“键盘按键”“键盘按下”“键盘释放”，可和鼠标步骤混合排序、录制及回放。录制使用 WH_KEYBOARD_LL 与 WH_MOUSE_LL，鼠标和键盘共享原生事件时间轴；回放使用 SendInput，保存扫描码及扩展键标志。

手动添加后将操作类型切换为键盘操作，点击“按键 / 组合键”输入框，按目标键或组合键；点击其他位置结束选择。单独的 Ctrl/Alt/Shift 等在松开时选择。键盘按键会按动作耗时自动释放；按下和释放可作为独立步骤控制长按。组合键的修饰键按顺序按下、逆序释放。输入按键时暂时挂起本工具的全局快捷键，避免把键位选择误判为运行/录制。

键盘参数支持与鼠标相同的橙色标记、单项还原、步骤还原、方案还原和撤回。F10 对键盘步骤不修改坐标。列表提供“仅键盘”筛选，也可搜索按键和组合键名称。

设置 → 录制与运行：

- **录制键盘操作**：默认开启，关闭后只录制鼠标。
- **录入本工具快捷键**：默认关闭，仅在录制键盘开启时生效。关闭时排除录制期间本工具的全局快捷键和方案快捷键，包括停止键及仅为该组合键按下的修饰键；此前正常用于其他操作的修饰键会保留。过滤后重新计算间隔，不压缩其他操作间的时间。
- 开启后保留这些快捷键；停止录制时如物理键尚未抬起，会补齐对应释放步骤。回放自身注入的控制键不会再次触发本工具的录制、暂停或停止；用户物理紧急停止仍优先响应，包括存在额外修饰键的情况。

回放停止、完成或异常时，只释放本工具已成功按下、且尚未释放的鼠标按键，以及仍持有的键盘按键；不会无条件发送左/右/中键释放。录制开始前触发的启动快捷键不属于录制时间范围。

键盘步骤是按键事件，不是独立的 Unicode 文本输入功能；输入结果受目标程序、当前键盘布局、输入法和剪贴板状态影响。安全桌面及更高权限窗口不保证可回放。

## 录制与回放

默认快捷键：

| 按键 | 操作 |
|---|---|
| F6 | 开始 / 停止录制，倒计时中可取消准备 |
| F7 | 运行 / 停止当前方案 |
| F8 | 紧急停止 / 取消倒计时 |
| F9 | 暂停 / 恢复回放 |
| F10 | 将当前鼠标坐标暂存到选中步骤的工作稿 |
| Ctrl+Alt+A | 空闲时在选中步骤后添加左键单击步骤，采用当前鼠标坐标 |

空方案（当前编辑稿与已保存版本都没有步骤）直接录入当前方案，不再弹出保存方式确认；已有步骤或已保存内容时，录制前选择覆盖当前方案、录制为新方案或取消。弹窗中的名称对两种保存方式都生效；保留原名另存时，会自动使用弹窗说明中的唯一新名称。覆盖只在录制正常结束并保存成功后更新名称和步骤。取消准备、启动失败或没有录到操作时，不修改原方案及名称。保存失败时保留录制草稿，可点击保存重试。

录制默认隐藏主窗口并倒计时 3 秒，再开始捕获键鼠输入。录制过滤本工具窗口上的键鼠操作，鼠标移动、点击和事件间隔逐事件保存；右键和双击表现为按下/释放序列。停止录制时先补齐缓冲事件，再提交录制。停止活跃录制会保存已经捕获的内容；取消倒计时不会开始捕获。

顶部倍速滑块范围 0.1–10×，1× 为原速；运行或暂停时调整立即作用于当前回放，同时作为方案工作稿的修改，之后保存可保留。次数 0 为无限循环；循环间隔只在两轮之间发生。Interval 是操作前等待，Duration 是移动、按住点击或等待耗时，滚轮一般以 120 为一格。倍速统一作用于间隔、耗时和循环间隔。

录制中禁止运行、编辑、切换方案和调整倍速；运行或暂停中禁止录制、编辑和切换方案。停止收尾时禁止启动新任务，释放按键后恢复空闲。

## 步骤查找

默认隐藏移动轨迹，只显示关键操作；可切换全部、仅点击/按键、等待/滚轮。支持搜索中文操作名、键盘按键/组合键、坐标、#原始编号，以及上一个/下一个关键操作定位。筛选不删除数据或改变回放时序。每行保持原始编号，编辑、删除和排序仍针对原步骤；排序按相邻原始步骤移动，包括被筛选隐藏的步骤。

## 设置

右上角“设置”，保存并应用后生效，取消不改变配置。

- **快捷键**：六个全局操作及当前方案独立快捷键。点击输入框直接按下按键或组合键，支持 Ctrl、Alt、Shift、Win。Tab 切换字段，Backspace 禁用方案快捷键。编辑设置时暂停本工具的全局快捷键，关闭后恢复；检查重复、系统占用，冲突时恢复原配置。提示随实际键位更新。
- **录制与运行**：录制准备时是否隐藏、录制结束后是否弹出主界面、倒计时 0–10 秒、是否记录移动轨迹、是否记录键盘、是否录入本工具快捷键；运行时是否隐藏主界面；录制快捷键提示开关、位置、透明度。运行隐藏默认关闭，开启后只在确认保存并真正开始回放时隐藏，结束、停止或错误后恢复。关闭录制结束弹窗后，可双击托盘图标重新打开。
- **外观与默认值**：浅色/深色主题、新方案默认倍速、次数和循环间隔。默认值只影响之后新建的方案，不覆盖已有方案。

关闭快捷键提示后，快捷键仍有效，数字倒计时仍显示。浮层不抢焦点、鼠标可穿透，位于开始时鼠标所在显示器。关闭移动轨迹后仍记录点击坐标与间隔，但不会保存拖拽路径。

设置在 `settings.json`，方案在 `plans.json`。旧版 keys.txt 与整数方案快捷键可迁移读取。步骤持久化 Id 用于在排序后准确匹配保存基准。导入导出针对单个方案；导入会禁用其独立快捷键以避免冲突。

## 回放计时

旧版逐事件相对 Task.Delay 会累积系统唤醒和界面调度误差。实测 160 个 2ms 间隔事件应为约 320ms，旧版约 2469ms。当前使用独立回放线程、Stopwatch 累计截止时间及运行期间的 1ms 定时器分辨率；暂停冻结虚拟时间，变速保持时间位置连续，录制使用原生鼠标事件时间戳。

回归检查使用模拟鼠标输出，不向真实桌面注入键鼠操作；存储使用内存或故障注入，不改写用户方案。覆盖：密集事件计时、倍速与实时变速、暂停与停止释放、异常清理、按钮状态、筛选/导航/排序、倒计时取消、组合键解析/冲突恢复、录制草稿保存与名称、保存失败恢复、独立编辑稿、F10 组合撤回、单项/步骤/整方案还原、未保存确认、修改边框、保存基准清理、重命名撤回冲突、运行隐藏入口时机，以及两主题、最小尺寸、放大字体布局。实际创建隐藏 HWND 验证浮层样式并验证原生组合键注册；实际创建和销毁托盘图标。

2.0 新增检查覆盖：真实键盘/鼠标低级钩子的安装卸载、键鼠共用时间轴、热键包含/排除、完整组合键修饰键过滤、修饰键复用、停止时补齐释放、回放按键顺序/扫描码/扩展键、键盘步骤不移动鼠标、停止和异常释放所有持有键、注入控制热键识别、物理紧急停止优先、额外修饰键安全停止、独立物理/注入按键状态、Pause 特殊键映射、INPUT ABI 大小以及键盘字段的修改/还原/筛选。

2.0.1 修复记录：此前鼠标清理无条件发送 0x54（左/右/中键释放），即使只有等待步骤，也产生额外右键释放。以可注入的鼠标传输接口复现失败后，改为持有状态跟踪，并验证空闲、等待、左键完整点击、纯键盘、按下失败均不生成无关释放；未完成的右键按下只释放一次。同时检查空方案录制不调用确认框、已有数据仍确认、隐藏主窗口时弹窗独立置前。

## 主要模块

Models：可观察的方案与步骤、AppSettings。
ViewModels：工作稿、筛选、显示状态和录制缓冲。
PlanEditTracker：保存基准、修改标记与逆操作撤回。
PlanStore：原子 JSON 保存与唯一名称管理。
MouseRecorder / RecordedInputBuffer：键鼠钩子、统一时间轴和录制热键过滤。
PlaybackClock / Engine / MouseOutput / KeyboardOutput：计时、状态机与 SendInput 输出及按键清理。
HotkeyOriginGate：识别本工具注入的控制键，保证物理紧急停止优先。
HotkeyManager / TrayService：全局组合键、恢复入口。
Views / Themes：设置页、录制浮层、更新窗口与主题。
UpdateService / MainWindow.Updates：版本查询、可信来源与安装包验证、空闲通知及关闭后安装。
tests：可重复执行的状态、计时、数据保护与布局回归检查。
